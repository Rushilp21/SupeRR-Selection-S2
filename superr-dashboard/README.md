# SupeRR Selector Season 2

Static competition dashboard. Serve `dist/` over HTTP; no build or dependencies are needed.

The dashboard uses the final analysis exports from `../final_analysis`, verified source portraits and the submission PDFs. Ranking data is a snapshot through 1 November 2026. The mean rank across 13 settings determines the order. It is a historical shortlist, not a validated forecast or confirmed auction list.

Files: `dist/index.html`, `dist/style.css`, `dist/app.js`, `dist/data.json`, `dist/assets/`, two report PDFs and two ranking CSVs.

Interaction: scroll-driven 3D card stack, direct rank navigation, batter/bowler toggles, searchable top-20 comparison and expandable metric definitions. Reduced-motion preferences replace the animated deck with a static list. Native scrolling is preserved.

Player image sources are linked in the page footer. The website is an independent competition submission and does not claim official Rajasthan Royals affiliation.
